"Su N fogli" gira il foglio quando serve
- **In Miniature, "Su N fogli" ora sceglie davvero il foglio orizzontale quando le miniature ci vengono più grandi.** Prima, con file molto orizzontali (per esempio due strisce sottili su un A4), WinFiles scartava il foglio orizzontale con una colonna sola perché controllava se ci stava un riquadro quadrato largo quanto il foglio, invece dell'altezza vera delle miniature: così restava sul verticale. Ora conta l'altezza vera, prova i due versi e tiene quello con le miniature più grandi. Il formato (A4 o A3) resta quello che scegli tu.
