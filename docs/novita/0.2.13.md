Esplora file
- Nuova voce **Apri in WinFiles** nel tasto destro di file, cartelle e sfondo di una cartella.
  Su Windows 11 per ora sta in "Mostra altre opzioni" (o Maiusc+F10).
- Tutti i file selezionati finiscono nella stessa finestra di WinFiles, anche se è già aperta:
  si aggiungono a Miniature come se li avessi trascinati.
