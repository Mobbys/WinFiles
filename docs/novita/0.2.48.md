Menu di Windows 11: l'aggiornamento non lo rompe più
- **«Apri in WinFiles» e «Invia al nesting» funzionano subito dopo ogni aggiornamento.** Il menu non resta più attaccato a Esplora file dopo che l'hai usato. Se al momento dell'aggiornamento è ancora in uso, WinFiles riavvia Esplora file da solo per qualche secondo (le finestre delle cartelle aperte si chiudono) e il menu nuovo è subito attivo.
