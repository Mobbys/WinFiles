Miniature
- La ricerca e i tipi scelti nell'elenco dei file valgono anche per i fogli, come nella 4.9:
  anteprima, stampa, PDF e riepilogo mostrano solo i file (o le pagine, se si cerca "catalogo 3")
  che l'elenco mostra. Sopra l'anteprima una striscia dice **"Ricerca attiva: N di M file"**, con
  **Mostra tutti** per rimettere tutto. Il lavoro salvato non cambia: svuotata la ricerca torna
  tutto com'era, comprese le pagine tolte a mano dalla stampa.
