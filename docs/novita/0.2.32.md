Anteprime nelle cartelle di Windows
- **Esplora file mostra il contenuto dei file** nelle viste a icone medie, grandi e molto grandi: PDF, AI, EPS, PSD, foto RAW, HEIC, WebP, TGA, SVG, DXF, DWG e PLT. Le disegna WinFiles, con gli stessi lettori delle miniature.
- I programmi predefiniti non cambiano: un PDF si apre sempre con il programma di prima.
- Se una cartella già vista mostra ancora le icone vecchie: Pulizia disco › spunta "Anteprime" › OK, poi riapri la cartella.
