Miniature
- Nuova casella **"Su N fogli"** nella barra in alto, accanto a "1 per foglio". Scegli quanti fogli
  vuoi (1, 2, 3…) e WinFiles mette tutte le miniature in stampa su quei fogli, più grandi
  possibile. Colonne e verso (verticale o orizzontale) li sceglie lui, provando tutte le
  combinazioni; mentre è accesa si vedono quelli scelti, e sopra l'anteprima c'è scritto, per
  esempio, "3 colonne, su 2 fogli". Il formato (A4 o A3) resta quello che scegli tu.
- Nel menu del tasto destro sui file c'è **"Stampa solo questo file"** (o "Stampa solo i N file
  scelti"): toglie dalla stampa tutti gli altri in un colpo. Insieme a "Su N fogli" serve a mettere
  solo alcuni file su pochi fogli, più grandi possibile.
