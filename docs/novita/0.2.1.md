Miniature
- Nell'elenco entrano tutti i file trascinati, di qualunque tipo: quelli che WinFiles non sa
  leggere (Word, testo, archivi…) hanno il loro nome, la nota e sul foglio un riquadro con
  l'estensione, senza anteprima né misure
- La casella "Includi i file non supportati" sopra l'elenco li toglie tutti insieme e, riaccesa,
  li rimette al loro posto; la scelta resta per le volte dopo
- Il pulsante "Altri" nel filtro mostra solo i file non supportati
- I file nascosti e quelli che Windows lascia nelle cartelle (Thumbs.db, desktop.ini, i file
  temporanei di Office) restano fuori
- Corretto: una cartella con sottocartelle e nomi di file in maiuscolo poteva comparire due volte
  nell'elenco e sul foglio
