Scala e strumenti delle note insieme
- **La scala funziona di nuovo con gli strumenti delle note aperti**: scegli le miniature e premi 1:10, 1:20…, accendi il Timbro o usa tasto destro › Scala, come prima.
- Premere «Scala» o accendere il Timbro rimette lo strumento Scegli, così il clic va alle miniature; scegliere uno strumento da disegno spegne il Timbro.
- **Niente più pulsante «Annota»**, né in Miniature né in Visualizza: gli strumenti delle note sono sempre visibili. La casella «Mostra annotazioni» nasconde le annotazioni quando servono i file puliti.
