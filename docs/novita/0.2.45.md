Miniature: trascinare le miniature e una nota per più file
- **Trascina le miniature nell'anteprima** per cambiare l'ordine, senza passare dall'elenco a sinistra. Una linea blu mostra dove finiscono; se ne hai scelte più di una (Ctrl o Maiusc) si spostano tutte insieme. Come nell'elenco, i file restano nella loro cartella.
- **Una nota su più file insieme**: scegli più file (nell'elenco o nell'anteprima, con Ctrl o Maiusc) e scrivi la nota una volta sola nel pannello Note: va su tutti. Se i file avevano note diverse il pannello lo dice, e ciò che scrivi le sostituisce. Nei file con più pagine la nota va sulla prima pagina.
