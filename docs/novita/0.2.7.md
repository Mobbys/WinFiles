Modifica PDF e Modifica immagini
- Le misure delle quote ora si scrivono: si clicca nel campo (o doppio clic sulla quota) e si
  scrive il numero; le altre si adeguano mentre si scrive.
- Nuovo pulsante **Stampa** (Ctrl+P) in Modifica PDF e Modifica immagini: stampa il file com'è
  adesso, anche con le modifiche non ancora salvate, alla misura vera. Con le quote accese
  escono anche le quote.
- Nel pannello delle quote, **Salva con le quote**: un PDF della pagina o dell'immagine con le
  quote disegnate sopra, alla misura vera. Il file originale non cambia.
