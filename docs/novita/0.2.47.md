Menu di Windows 11 dopo un aggiornamento
- **«Apri in WinFiles» e «Invia al nesting» non si rompono più dopo un aggiornamento.** Se Esplora file tiene in uso il menu della versione di prima, Windows lo aggiorna da solo al prossimo accesso. Intanto una barra in WinFiles propone **Riavvia Esplora file**, che lo aggiorna subito: le finestre delle cartelle si chiudono e la barra di Windows sparisce per qualche secondo.
- **File delle note**: un lavoro da cui hai tolto tutte le note non viene più proposto. Se ne resta uno solo, il doppio clic lo apre direttamente senza chiedere.
