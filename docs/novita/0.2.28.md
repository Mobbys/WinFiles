Visualizza (scheda nuova, la prima a sinistra)
- Guarda **PDF, Illustrator, EPS, immagini e disegni DXF/DWG** senza cambiarli.
  - Misure vere in mm o cm, con al vivo, abbondanza per lato e m².
  - Zoom nitido a ogni ingrandimento: Ctrl+rotella verso il puntatore, barra spaziatrice o tasto
    centrale per spostarti.
  - Righelli, riquadri al vivo e abbondanza, quote, "Copia misure".
- **Tinte piatte**: l'elenco con colore, pagine, sovrapposizione, ruolo (Taglio, Cordone…) e
  lunghezza delle linee. Un clic su una tinta sbiadisce il resto e la mette in evidenza.
- **Frecce** per il file precedente e seguente della cartella; più file aperti nelle linguette.
- **Doppio clic su una miniatura** (o su un file dell'elenco) lo apre in Visualizza su quella
  pagina. Le frecce scorrono i file del lavoro e "← Miniature" torna dove eri.
- **Passa a** (Ctrl+1…6) manda il file in Miniature, Modifica PDF, Tracciati, Modifica immagini,
  Fustella o Nesting. "Apri con…" apre il file con un altro programma.
- **Stampa con anteprima**:
  - A4 o A3, misura vera, percentuale o adattato; per i disegni scala 1:N.
  - Il file si può dividere in **tasselli** da unire, con sovrapposizione e crocette.
  - Bordo non stampabile, didascalia con nome, scala e tassello, stampante calibrata.
- **DXF e DWG**: fondo nero come nei CAD (o bianco), layer da accendere e spegnere, unità da
  scegliere se il file non le dice. In stampa tutto in nero.

Esplora file
- Nel tasto destro di PDF, AI, EPS e immagini c'è **"Invia al nesting WinFiles"** (anche nel menu
  corto di Windows 11). Se WinFiles è già aperto, i file vanno nella stessa finestra.
- Aiuto › **Programma predefinito…**: scegli per quali file il doppio clic apre WinFiles in
  Visualizza. All'installazione non cambia niente: si conferma nelle Impostazioni di Windows.
