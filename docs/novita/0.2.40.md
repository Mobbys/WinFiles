Apri in Acrobat, Illustrator, Photoshop… con un clic
- **Pulsanti «Apri in …»** in Visualizza, Modifica PDF e Modifica immagini: per un PDF trovi «Acrobat» e «Illustrator», per un JPG «Foto» e «Photoshop», con l'icona vera del programma. Se scegli due programmi per un tipo vedi due pulsanti, se ne scegli uno vedi un pulsante. Con la finestra stretta resta solo l'icona.
- **Ctrl+Maiusc+1, 2, 3…** aprono il primo, il secondo, il terzo programma del file che stai guardando.
- **Tasto destro › Apri in** sui file di Miniature, sulle pagine di Visualizza, nell'elenco di Modifica immagini e nel Nesting. Con più file scelti si aprono tutti insieme.
- **Aiuto › Programmi esterni…** (o la matita accanto ai pulsanti): per ogni tipo di file scegli i programmi, cambi l'ordine, il nome sul pulsante, ne aggiungi uno trovato sul PC o qualunque .exe con «Sfoglia…». La prima volta WinFiles mette da solo quelli consigliati che ha trovato.
- Acrobat si apre alla pagina che stai guardando.
- Se in Modifica PDF o Modifica immagini ci sono modifiche non salvate, WinFiles chiede se salvarle prima: l'altro programma apre il file com'è su disco.
- Quando salvi il file nell'altro programma, WinFiles se ne accorge e lo rilegge (misure, miniature, Visualizza).
