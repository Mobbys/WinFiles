Miniature: il file delle note riapre il lavoro com'era
- **Doppio clic su note.winfiles**: riapre tutti i file del lavoro in cui hai scritto le note, anche quelli senza note, nello stesso ordine e con lo stesso foglio, verso e colonne. Prima arrivavano solo i file con note e "Su N fogli" poteva girare il foglio: ora le pagine tornano identiche.
- **Più lavori nella stessa cartella**: se nella cartella hai fatto più impaginati con le loro note, il file delle note li ricorda tutti e ti chiede quale aprire (con i primi nomi, quanti file, quanti con note e quando).
- Una freccia che arriva su un file senza note porta anche quel file, così non resta appesa.
